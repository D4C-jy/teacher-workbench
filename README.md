# 教培工作台

给教培老师自己用的**单机**工作台：看今天的课、查学生还剩多少课时、记录无人机的取用与交回，月底看自己的到课率和业绩。

所有数据存在**本机一个 SQLite 文件**里，不联网、不上传、不需要注册云账号。

当前版本：**v0.7** — 六个模块全部可用，已可打包成 Windows 安装包。

---

## 两种打开方式

### 方式一：安装包（日常使用）

```
release-slim/TeacherWorkbench-Setup-0.1.0.exe     102 MB
```

双击安装，可选安装目录，装完桌面和开始菜单会有「教培工作台」图标。
装完占约 287 MB（其中 250 MB 是 Electron 内置的 Chromium，无法再压）。

> **首次运行会被 Windows 拦一次**：因为没有购买代码签名证书，会提示"Windows 已保护你的电脑"。
> 点 **更多信息 → 仍要运行** 即可，之后不再提示。

### 方式二：源码运行（改代码时用）

双击 **`启动工作台.bat`**。

第一次会自动装依赖（几分钟），之后每次几秒。浏览器会自动打开。
关掉黑色命令行窗口 = 停止程序。

> 需要 Node.js 22 或更新版本。

两种方式**用的是同一套代码**，只是壳不同；数据也各自独立（源码版在 `data/`，安装版在 `%APPDATA%`）。

## 第一次使用：三步引导

安装后第一次打开会走一个引导，不是直接进界面：

**① 创建账号**
用户名（如 `wanglaoshi`）、显示名（如 `王老师`）、密码（至少 6 位）。
密码用 scrypt 加盐哈希存在本机，不存明文。

**② 选择数据存放位置**
这里会明确告诉你数据现在存在哪个目录，并给一个「选择文件夹…」按钮，点开就是系统的文件夹选择框（不用手打路径）。
建议放非系统盘（如 `D://教培工作台数据`），重装系统不丢。
选完会自动复制过去，然后提示重启一次生效——点「立即重启」会自己关掉再打开，回到这一步继续。
不想改就点「用默认位置，下一步」。

**③ 选择怎么开始**
- 先用演示数据熟悉（12 名学员、3 个班、5 台无人机）
- 从空白开始（清空演示数据）

点「进入工作台」就完成了，以后打开直接是登录页。

一台电脑可以注册多个账号（多个老师共用），但**学员和课时数据是共享的**。

会自带一份演示数据：12 名学员、3 个班、5 台无人机，方便先熟悉界面。不需要了可以删掉数据库文件重来（见下文「数据与备份」）。

## 六个模块

### 今日 —— 教室平面图

首页把工作画成一张俯视平面图，四间：**主讲教室 / 器材间 / 前台 / 走廊**。

- 学生是真的坐在座位上，头顶名牌直接显示「姓名 + 剩余课时」
- 课时 ≤ 阈值（默认 3）自动标红，一眼看谁该续费
- 人物有轻微的呼吸动画，每个座位节奏不同
- 右侧面板：今日课程、待处理（课时不足 / 未交回器材 / 即将到期）、本周消课

### 课表

- 周视图，今天那列淡蓝底，可切上一周 / 下一周
- 点任意课程 → 右侧详情：标记已下课、撤销、停课、恢复、调到其他时段
- **排课**：右上角「＋ 排课」，两种模式
  - 每周固定：这个班以后每周几都上
  - 只加这一次：临时补课
- 时段用**双把手滑块**自由拖（07:00–22:00，15 分钟一档），不是固定几个选项

### 学员 · 课时

- 列表按剩余课时从少到多排，告急的排最前
- 搜索、按班级筛选、导出 CSV（Excel 直接能开）
- 点开右侧详情：剩余课时、课时包、到期日、**全部流水**
- **＋ 充值课时**：填节数、报名金额、备注、有效期
- **消课**：在课表点某节课 → 右侧「消课」→ 勾到场学生 → 确认。每人扣 1 课时，已扣过的自动跳过

### 器材

- 卡片台账：编号、型号、状态（在库 / 取用中 / 维修 / 停用）
- **取出**：填取用人（老师或机构）、用途（上课 / 外拍 / 送修 / 调拨 / 其他）、预计交回时间、取出时机况
- **交回**：填交回时机况，可勾选「转入维修」
- **记录**：每台的全部取用历史
- **打印标签**：A4 三列二维码标签，贴机身侧面，扫码显示编号
- 导出台账 CSV

### 个人中心

按月统计，可切上/下月：

| 指标 | 算法 |
|---|---|
| 总上课课时 | 本月消课流水求和 |
| 到课率 | 实到人次 ÷ 应到人次（课次数 × 班级人数） |
| 续费率 | 本月有充值的学员 ÷ 在读学员 |
| 业绩金额 | 本月充值金额合计 |

下方是每日消课柱状图。所有数字都是从流水和课次算出来的，没有手工填写的。

### 设置

- **提醒阈值**：低于几节标红（改动立即生效）
- **到期提醒**：多少天内到期
- **学期开始日**：用于计算"第几周"
- **上课时段**：查看每段被几条规则、几节课引用；无引用的可删除
- **数据**：当前存放位置、更改位置、一键下载备份

## 数据与备份

**安装版首次启动会让你选一个目录**，默认建议 `D://教培工作台数据`（有 D 盘的话），
不用默认塞在系统盘。选完记在 `%APPDATA%\教培工作台\location.json`，数据文件在 `<你选的目录>\workbench.db`。

源码版：`teacher-workbench\data\workbench.db`

**想换位置**：设置 → 数据存放位置 → 「选择新位置…」，直接弹系统文件夹选择框，选完自动迁移，点「立即重启生效」。
原目录的文件不会自动删除，确认新位置正常后自己删掉即可。

**整个数据库就是一个文件**。

- **备份**：设置页点「下载备份」，生成的是 SQLite 快照（运行中也能安全备份）
- **还原**：关掉程序 → 用备份文件覆盖上面那个路径 → 重新打开
- **重来**：删掉这个文件，重新打开就是全新状态

课时余额**不存字段**，永远由流水实时算：

```
余额 = Σ充值 − Σ消课 + Σ冲正
```

所以任何一个数字都能在学员详情的流水里对上账。

## 开发

```bash
npm install

npm run dev        # API(4317) + Vite(5173)，浏览器自动打开
npm run build      # 前端生产构建 -> dist/
npm run build:all  # 前端 + 后端单文件打包 -> dist-server/
npm run app        # 用 Electron 直接跑（不打包）
npm run pack:slim  # 出精简安装包 -> release-slim/（推荐，102MB）
```

### 技术栈

| 层 | 选择 | 说明 |
|---|---|---|
| 前端 | React 18 + TypeScript + Vite 6 | |
| 样式 | 原生 CSS + CSS 变量 | 约 1000 行，令牌集中管理 |
| 后端 | Node 22 + Express 4 | |
| 数据库 | `node:sqlite`（Node 内置） | 零原生编译，不需要 MSVC |
| 认证 | scrypt + token 表 | 不引 bcrypt / jwt |
| 字体 | 微软雅黑 | 系统字体，零加载成本 |
| 桌面壳 | Electron 45 + electron-builder | 内嵌同一个 Express 服务 |


### 打包说明

`npm run pack:slim` 做的事情：

1. 前端构建 + 后端 esbuild 打成单文件
2. 组装 `build-slim/win-unpacked`：只带 **zh-CN / en-US** 两个语言包（原版有 55 个，占 49MB），
   并去掉 `dxcompiler.dll`（25MB，仅 WebGPU/D3D12 需要，普通界面用不到）
3. 调 `electron-builder --prepackaged` 直接出 NSIS 安装包

体积对比：

| | 完整打包 | 精简打包 |
|---|---|---|
| 解压后 | 359 MB | **287 MB** |
| 安装包 | 116 MB | **102 MB** |

> 在普通机器上也可以直接 `npm run dist`（完整打包，输出到 `release-app/`）。
> 但在本机沙箱环境里 electron-builder 解压时会因为目录重命名被拦而失败，所以用 `pack:slim`。

## 常见问题

**双击 bat 后窗口一闪就没**
Node 没装或不在 PATH。装 Node 22 后重试。

**浏览器没自动打开**
手动访问 http://localhost:5173

**提示端口被占用**
默认 5173（前端）和 4317（API）。改 `vite.config.ts` 与 `server/index.ts` 里的端口，两处要一致。

**页面一直「加载中」**
API 没起来。看命令行窗口报错，或单独跑 `npm run dev:server` 排查。

**安装版数据在哪 / 重装会不会丢**
在 `%APPDATA%\教培工作台\data`，重装和卸载都不动它。

**安装时被 SmartScreen 拦**
点「更多信息 → 仍要运行」。没买签名证书，属正常现象。

## 已知限制

- 安装包**未签名**，首次运行会被 SmartScreen 提示一次
- 安装包已裁掉 53 种语言包和 `dxcompiler.dll`；如果某台机器上出现界面白屏，说明该机 GPU 走 D3D12 且缺该库，需换回完整打包
- 平面图按 1120px 以上宽度设计，窗口太窄会挤
- 二维码扫出来是器材编号纯文本，暂不能跳转到详情
- 多账号共享同一份数据，没有做权限隔离
