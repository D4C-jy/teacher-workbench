# 教培工作台

给教培老师自己用的单机工作台。查看学生剩余课时、今日课表、无人机取用情况。

当前版本：**v0.1（M0 骨架）** — 开发阶段，浏览器打开，暂不打包安装。

---

## 怎么打开

双击 **`启动工作台.bat`**。

第一次运行会自动安装依赖（几分钟），然后自动打开浏览器。
之后的每次启动只需要几秒。

> 需要 Node.js 22 或更新版本。本机已装 22.22，无需额外操作。

关掉那个黑色命令行窗口 = 停止程序。

## 第一次使用

打开后会看到**注册**页面（因为本机还没有账号）：

1. 用户名：随便起，例如 `wanglaoshi`
2. 显示名：例如 `王老师`
3. 密码：至少 6 位

注册后自动进入工作台。密码用 scrypt 加盐哈希存在本地，不联网、不上传。

之后再打开就是登录页。想重置全部数据：关掉窗口，删除 `data/workbench.db`，重新启动即可。

## 课表怎么用

- 顶部箭头切上一周 / 下一周，右边「回到本周」
- 点任意课程卡片 → 右侧出详情面板
- 面板里可以：**标记已下课**、**撤销下课**、**停课**、**恢复**、**调到其他时段**
- 今天那一列有淡蓝底色
- 停课不会删除记录、不扣课时；调时段只改这一节，不动每周固定课表

### 排课

点右上角 **＋ 排课**，两种方式：

| 方式 | 用途 | 效果 |
|---|---|---|
| **每周固定** | 这个班以后每周几都上 | 写入周规则，之后每一周自动出现 |
| **只加这一次** | 临时补课、加课 | 只往选中的那一天加一节，不重复 |

填班级、星期（或日期）、时段、教室即可。同一个班在同一时段重复排会提示"已经有固定课了"。

课表按「周规则」自动展开：每个班在哪天哪一节上课是规则，每周自动生成课次。
改规则目前要改数据库（M1.1 会加上「课程与班级管理」界面）。

## 学员 · 课时怎么用

- 左边是学员列表，按剩余课时从少到多排，≤3 标红
- 顶部可以搜索姓名、按班级筛选、导出 CSV（Excel 直接能打开）
- 点一个学员，右边显示：剩余课时、课时包、到期日、**全部流水**
- **＋ 充值课时**：填节数和备注，写一条 charge 流水
- **消课**：在课表点某节课 → 右侧"消课" → 勾到场的学生 → 确认。每人扣 1 课时，
  已经扣过的人会自动跳过，不会重复扣

余额不存字段，永远由流水算出来：`充值 − 消课 + 冲正`。所以任何数字都能在流水里对上账。

## 数据在哪

```
teacher-workbench/data/workbench.db
```

单文件 SQLite，直接复制这个文件就是完整备份。删除它等于清空重来。

课时余额不存成字段，而是由流水求和得出：

```
余额 = Σ充值 − Σ消课 + Σ冲正
```

所以每一分课时都能追溯到「哪节课、什么时候、什么原因」。

## 技术栈

- 前端：React 18 + TypeScript + Vite 6，原生 CSS 变量
- 后端：Node 22 + Express 4
- 数据库：`node:sqlite`（Node 内置，零原生编译）
- 认证：`node:crypto` scrypt + token 会话

端口：前端 5173，API 4317。两个端口被占用时改 `vite.config.ts` 与 `server/index.ts`。

## 常见问题

**双击后窗口一闪就没了**
说明 Node 没装或不在 PATH。装 Node 22 后重试。

**浏览器没自动打开**
手动访问 http://localhost:5173

**提示端口被占用**
关掉其他占用 5173 / 4317 的程序，或修改端口后重新启动。

**页面一直显示「加载中…」**
API 没起来。看命令行窗口有没有报错；`npm run dev:server` 可以单独启动后端排查。
